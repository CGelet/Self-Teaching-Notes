# React / Next.js Structure and Outline
## What is React and Next.js?  
Next.js is React framework that give you building blocks to create fase, full-stack web applications.

## What are the building blocks of a web application.
- **User Interface** - What the user interacts with.
- **Routing** - How users navigate between different parts of your application.
- **Data Fetching** - Where your data lives and how to get it.
- **Rendering** - When and where you render static or dynamic content.
- **Integrations** - What third-party services you use.
- **Infrastructure** - Where you deploye, store, and run your application code.
- **Performance** - How to optimize your application for end-users.
- **Scalability** - How your applications adapts as your team, data, and traffic grow.
